1. Executive Overview

Migration Summary

This document details the complete migration of the Payments Division - Plastic Issuance & Settlement mainframe application from legacy COBOL/DB2/CICS/JCL to a modern Java 21 + Spring Boot 3 + PostgreSQL 16 + React 18 stack.


Key Achievements:

  • 13 COBOL programs migrated to 3 Java service classes with full business logic preservation
  • 4 COBOL copybooks mapped to 4 JPA entity classes with identical field structures
  • DB2 tables migrated to PostgreSQL 16 with H2 in-memory fallback for local development
  • JCL batch jobs replaced with Spring Batch framework + REST-triggered pipelines
  • CICS/BMS 3270 green screens replaced with modern React 18 responsive web UI
  • Wells Fargo POC standard theme applied throughout the application
  • localStorage fallback ensures application works without database connectivity

8. Business Logic Preservation

8.1 Luhn Algorithm (PICRD100 GENERATE-CARD-NUMBER)

COBOL (Original)
GENERATE-CARD-NUMBER.
    MOVE WS-BIN-PREFIX TO WS-CARD-PARTIAL(1:6)
    MOVE WS-CARD-SEQ   TO WS-CARD-PARTIAL(7:9)
    PERFORM CALCULATE-LUHN-CHECK
    STRING WS-CARD-PARTIAL DELIMITED SIZE
           WS-CHECK-DIGIT  DELIMITED SIZE
           INTO WS-CARD-NUMBER
    END-STRING.
Java (Migrated)
public static String generateCardNumber(int sequence) {
    String bin = "400012";
    String seqStr = String.format("%09d", sequence);
    String partial = bin + seqStr;  // 15 digits
    int checkDigit = calculateLuhnCheckDigit(partial);
    return partial + checkDigit;    // 16 digits
}

8.3 O(n) Sequential Merge Matching (STLMT200)

Algorithm: Both settlement and acquirer records sorted by txn_id, then merge-walked in O(n) time complexity. This preserves the COBOL DFSORT + sequential file merge pattern. 
// Java implementation mirrors STLMT200.cbl lines 189-212
while (si < pendingTxns.size() && ai < acquirerConfirmations.size()) {
    int cmp = stlKey.compareTo(acqKey);
    if (cmp == 0) {
        // Keys match - verify amounts
        if (amounts match) { status = "MT"; matchedCount++; }
        else { status = "DI"; amountMismatch++; }
        si++; ai++;
    } else if (cmp < 0) {
        // Settlement unmatched
        status = "UM"; si++;
    } else {
        // Acquirer unmatched
        ai++;
    }
}

Fee Calculation
